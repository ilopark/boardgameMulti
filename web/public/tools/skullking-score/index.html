스컬킹 점수 계산기

라운드마다 입찰과 실제로 딴 트릭 수를 넣으면 정확한 점수와 누적 순위를 자동으로 계산합니다. 종이에 적을 필요 없이 바로 쓰세요.

보너스(입찰을 정확히 맞혔을 때만 적용): 색깔 14 +10, 검정 14 +20, 인어로 스컬킹 잡기 +50, 스컬킹으로 해적 잡기 +30. 보너스 칸에 합산 점수를 넣으세요.

점수 규칙 요약

  • 입찰 > 0, 정확히 맞힘: 입찰 수 × 20점 (+보너스)
  • 입찰 > 0, 빗나감: 빗나간 트릭 1개당 −10점
  • 입찰 = 0, 성공: 라운드(카드 수) × 10점
  • 입찰 = 0, 실패: 라운드(카드 수) × −10점

자세한 규칙은 스컬킹 규칙, 이기는 법은 스컬킹 전략을 참고하세요.
